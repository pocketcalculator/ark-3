# GIF assets

`original-color-pulse.gif` and `original-bouncing-bars.gif` are original placeholders included so the extension works immediately.

The repository intentionally does **not** contain the Duck Hunt dog animation.
The optional configured slot expects an asset the user is authorized to use at:

```text
duck-hunt-dog-authorized.gif
```

Do not commit it unless its terms permit redistribution. For supported asset
requirements, customization steps, configuration references, and validation,
see [`../README-GIF-EDITING.md`](../README-GIF-EDITING.md).
